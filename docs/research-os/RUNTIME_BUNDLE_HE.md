# קשירת רכיבי מודל פעילים לגרסה ניתנת לבדיקה

החבילה שומרת טביעות SHA-256 של המשקולות, קובצי הכיול, מודל היישור המקומי וקוד החילוץ/ההכרעה/הצגת המשוב. שם הקובץ ורשימת מחלקות משותפת אינם מספיקים לזיהוי גרסה. חבילת legacy היא **תיעוד מצב שנצפה**, ואינה הוכחה בדיעבד שכל רכיב אומן על ה־CNN הנוכחי.

## יצירה ואימות

יש ליצור את החבילה לאחר סיום השינויים בקוד שאותו היא קושרת:

```bash
venv/bin/python -m research_os.model_bundle create \
  --out results/research_os/runtime/observed_release_v1.json

venv/bin/python -m research_os.model_bundle validate \
  --bundle results/research_os/runtime/observed_release_v1.json
```

הכלי מסרב לדרוס קובץ קיים, ומאפשר יצירת תוצאה רק בתוך תיקיית התוצאות המקומית המוחרגת. הוא אינו מוריד מודלים ואינו מפעיל `torch.load` או inference.

אם נבחר מועמד לכיול ערוצים, יש לקשור אותו במפורש:

```bash
venv/bin/python -m research_os.model_bundle create \
  --channel-policy results/research_os/channel_cal/review_policy.json \
  --out results/research_os/runtime/observed_candidate_v1.json
```

אפשר להשתמש גם במשתנה `TAAMIFY_CHANNEL_CALIBRATION`; הבחירה נרשמת בחבילה. אותה בחירה צריכה להישמר בשרת. שינוי שלה מבלי ליצור חבילה תואמת גורם לכשל אימות.

## תוכן ובדיקות

- CNN התורה, verify head, sequence tagger וכל ארבעת ערוצי הדקדוק.
- כיול כללי ופר־מחלקה, ובחירה מפורשת של מועמד ערוצים אם יש כזה.
- משקולות CTC מקומיות, config, vocab, preprocessor ו־tokenizer.
- קוד השרת, המאמנים, החיתוך/היישור, הניקוד, חומרת השגיאות והמשוב, כולל מסך התרגול.
- פרמטרי frontend שנקראו מ־AST ללא ייבוא השרת, גרסאות ספריות, commit וטביעת השינויים המקומיים.
- סדר מחלקות כאשר אפשר לקרוא אותו כרשימת מחרוזות מתוך מטא־נתוני checkpoint באמצעות `pickletools`. קובץ ישן המשתמש באובייקטי NumPy שאינם נקראים בצורה הזאת מסומן כלא נקרא; לא מריצים pickle כדי להעמיד פנים שהמידע אומת.

המאמת דוחה חבילה פגומה או ששונתה, תפקיד חסר/כפול, קובץ חסר או ששונה, שינוי גרסאות ספריות, אי־התאמת סדר מחלקות כאשר הסדר זמין, בחירת כיול שונה, נתיב מוחלט, מעבר `..` וקישור סמלי היוצא משורש הפרויקט.

סטטוס התיעוד הוא `observed_binding_not_training_provenance`. אימון חדש צריך לשמור בעת האימון את טביעות הנתונים, ה־encoder וה־CNN שעליו נשענים הראשים; זוהי דרישה נפרדת מתיעוד המצב הנוכחי.

## חיבור לשרת

החיבור המפורש מיועד למשתנה `TAAMIFY_RUNTIME_BUNDLE`. בתחילת חיי השרת קוראים ל־`load_bundle(path, project_root, expected_options)` לפני קבלת בקשות אודיו. `expected_options` חייב לשקף את בחירת הכיול הפעילה ולא רק את זו שבקובץ החבילה.

`public_summary` מחזיר digest, סטטוס ושמות תפקידים בלבד. נתיבי דיסק, שמות משתמשים והקלטות אינם מופיעים בתשובה הציבורית. ללא בחירת חבילה הסטטוס הוא `unbound`, ואין לסמן אותו כאילו האימות בוצע.

בדיקת קובץ בעת עלייה קושרת את המצב באותו רגע. שינוי משקולות של שרת שכבר טען אותן לזיכרון מחייב הפעלה מחדש ואימות חדש; אין לערוך קובצי גרסה תוך כדי הגשה.
