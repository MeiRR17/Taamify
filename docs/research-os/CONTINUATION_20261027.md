## שחזור מקומי

```bash
venv/bin/python -m unittest research_os.test_channel_calibration research_os.test_channel_server research_os.test_plan -v
node research_os/test_practice_channels.js

# קובץ חדש בכל הרצה; השורות והמשקולות נשארות מקומיות
venv/bin/python -m research_os.prepare_channel_candidate \
  --out results/research_os/channel_cal/review_policy.json

# שני שרתי בדיקה, בטרמינלים נפרדים. אין לפגוע בשרת קיים על 8000.
OMP_NUM_THREADS=1 HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 \
  venv/bin/python -m uvicorn webapp.server:app --host 127.0.0.1 --port 8078
TAAMIFY_CHANNEL_CALIBRATION=results/research_os/channel_cal/review_policy.json \
  OMP_NUM_THREADS=1 HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 \
  venv/bin/python -m uvicorn webapp.server:app --host 127.0.0.1 --port 8079

venv/bin/python -m research_os.replay_channel_candidate \
  --baseline http://127.0.0.1:8078 --candidate http://127.0.0.1:8079 \
  --per-parasha 5 --out results/research_os/channel_cal/review_replay.json
```

Rollback של מועמד: מפסיקים את שרת הבדיקה ומפעילים בלי המשתנה
`TAAMIFY_CHANNEL_CALIBRATION`. אין צורך לשחזר checkpoint.
