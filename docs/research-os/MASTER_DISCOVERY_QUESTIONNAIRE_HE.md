# Taamify — שאלון עומק לקראת תוכנית הגמר האקדמית והמוצרית

**גרסה:** 1.0 | **תאריך:** 26.10.2026

**מטרת המסמך:** לאסוף החלטות, מידע וחוסרים לפני כתיבת תוכנית גמר מחייבת, כדי ליצור מחקר מדעי תקף ומוצר שניתן לסמוך עליו.

**איך עונים:** תחת כל שאלה אפשר לכתוב תשובה חופשית. אם מידע חסר, כתוב `לא ידוע`, `להחליט עם המרצה` או `לא רלוונטי`. שאלות המסומנות **[ליבה]** קובעות החלטות מעצבות ארכיטקטורה; אפשר לענות קודם עליהן, אך כל השאלות נשארות במסמך.

**פרטיות:** אין לכתוב כאן סיסמאות, טוקנים, פרטי קשר של קטינים או מידע מזהה של בעלי קולות. תשובות רגישות נשארות בעותק פרטי; ל־GitHub מעלים רק תשובות שאושרו לשיתוף.

## מה כבר ידוע לפי התיעוד והדיווחים (לא שאלות שיש לענות עליהן מחדש)

- **תחום מחקר:** זיהוי טעמי המקרא והוראה מתקנת מתוך אודיו, בדגש על נוסח ספרדי־ירושלמי.
- **תשתית קיימת:** Python/PyTorch, FastAPI, שרת מקומי, מערכת תורים; תוכנית Research OS עם P00–P12 ו־A00–A08.
- **שלב א׳:** על קורא בן13 בלבד; דווחו בדיקות API על שמונה פרשות שלא נראו באימון.
- **בדיקה מורחבת:** לפי דוח הסוכן שהועבר: דיוק 85.7%, AUC 0.993, התרעת שווא 2.1%, זיהוי שגיאות Proxy בשיעור 92.0%, אפסים על תקין 1.5%.
- **הסתייגות A4:** טעויות Proxy נוצרו משינוי הטעם המצופה לקריאה נכונה; טרם הוצגה הוכחת Recall על שגיאות תלמידים אמיתיות.
- **הסתייגות כיול:** ספי המערכת כוילו בעבר בעיקר על פרשות בראשית; בדיקת 8 הפרשות מחזקת אך אינה מבחן סופי מנותק לחלוטין מכיול.
- **המשך מוצרי:** כיול stress, dagesh, guttural, sheva; בחינת קוראים חדשים וגיוס הקלטות אמיתיות.
- **סטאק Dvir OS:** Next.js/RTL כ־Control Plane; מנוע האימון נשאר ב־Taamify, עם שידור מדדים מסוננים בלבד.
- **חומרה מתועדת:** MacBook Pro M1 Max / 64GB, MacBook Air M4 / 16GB, Windows עם GPU שלא אומת סופית.
- **שעות אימון:** 51 התאמות מודל ו־1,350 fit-epochs הן מסגרת תכנון — לא שעות GPU מדודות.

## פערים שחשוב לאמת מיד

- יש לקבל את **הנוסח המקורי** של דרישת המרצה/המוסד. הוא לא נמצא עדיין במסמכים שנבדקו.
- מדד A3 בבדיקה המורחבת (2.1%) הוא **מעל** היעד המקורי (≤2%), גם אם הפער קטן.
- מדד A4 של 92.0% הוא על **שגיאות Proxy**, ולא מעיד עדיין על Recall כלפי טעויות אמיתיות של תלמידים.
- המבחן המדעי המרכזי — הכללה לקוראים אמיתיים חדשים בנוסח הנבחר — עדיין מחייב איסוף ותיוג עצמאי.

## נספח — חומרים שאפשר לצרף אחרי מילוי

- הודעת המרצה/מחוון ההערכה/מועדי הגשה.
- מצב Branch ו־SHA מקומי של Taamify, קישורי PR ו־Issues.
- Stage A replay, ציוני ערוצי דקדוק, סכמת נתונים (ללא חומר מזהה).
- רשימת משאבי חומרה בפועל ותוצאות Benchmark דקות לאפוק.
- דוגמאות מותרות לשיתוף של תיוג Gold ודו"ח מומחה, ללא הקלטות רגישות.

## מה נבנה אחרי שהשאלון יתמלא

1. מסמך Scope מוסכם ו־Research Proposal לאישור המרצה.
2. פרוטוקול ניסויים מאושר מראש: שאלות, השערות, מדדים, קבוצות, אפיון Gold וקבוצת מבחן נעולה.
3. ארכיטקטורת Reference מלאה, Data Contracts, Pipelines, תלויות ו־ADRs.
4. תוכנית שעות אדם ושעות מחשב **מבוססת מדידות**, Timeline, שלבי Gate ותקציב סיכונים.
5. תוכנית מוצר PRD ו־Quality/Release Gates נפרדים מהצלחה מחקרית.
6. GitHub Issues/PRs ותצוגה אחודה ב־Dvir OS, אחרי אישורי תפעול ואבטחה.
7. מפרט מאמר/תזה/הגשה ומארז שחזור אקדמי.
